## 一、术语补全（P0 · 约新增 25 条，166→191）

### 1A. 高教育价值 · 立即补（15 条）

| 术语 | 分类 | 理由 |
|---|---|---|
| 3DES | modern | DES→AES 过渡桥梁，DES 卡已提 |

| Trapdoor Function | basic | RSA 的数学本质 |

| Steganalysis | methods | 隐写工坊已提及但无词条 |
| Double Ratchet | protocol | Signal 协议核心，端到端加密的标杆 |
| Kerberos | protocol | 最广泛部署的认证协议 |
| Discrete Logarithm | basic | DH/ECC/DSA 的共同难题 |
| Random Oracle | theoretical | 密码学证明的核心模型 |
| Forward Secrecy (PFS) | protocol | TLS 1.3 的核心特性，TLS 卡已提及 |
| SHA-3 / Keccak | modern | 与 SHA-2 并列的现行标准 |
| Miller-Rabin | methods | 素性测试标准（BigInt RSA 卡已在用） |
| Chinese Remainder Theorem | basic | RSA 加速与多项式插值的理论基础 |
| Hash-Based Signatures | post-quantum | SLH-DSA (FIPS 205) 的基础 |

## 二、正文术语 hover 扩展（P0 · 3→20 条）

story.html GLOSS_NOTES 从 3 条扩到 20 条，覆盖 c5-c11 高频概念：

| 术语 | 出现章节 | hover 内容要点 |
|---|---|---|
| 加表 | c6 | 附加在码组上的密钥数字表，定期换版 |
| 深度 | c6 | 同版加表期内两封密电相减抵消加表 |
| 转子 | c5 | Enigma 的核心旋转盘，每次按键步进一格 |
| 插线板 | c5 | Enigma 前面板的字母对交换装置 |
| 反射器 | c5 | Enigma 内部使加密=解密的固定反射盘 |
| 差分 | c8/c13 | 相邻比特/块的异或差值，统计分析的起点 |
| 熵 | c10 | 香农定义的信息不确定性度量 |
| 完美保密 | c10 | 密文与明文统计独立（OTP 的性质） |
| 公钥 | c10 | 可公开的加密密钥，与私钥配对 |
| 哈希碰撞 | c10 | 两个不同输入产生同一哈希输出 |
| QKD | c11 | 量子密钥分发的缩写 |
| 筛选密钥 | c11 | BB84 中双方保留基匹配部分的密钥 |
| QBER | c11 | 量子误码率，超过阈值即判定窃听 |
| 差分分析 | c13 | 通过对比输入/输出差分来攻击分组密码 |
| 字验 | c1/c2 | 北宋以诗配军情的验证体系 |
| 反切码 | c2 | 戚继光以两首诗的声母韵母交叉编密 |
